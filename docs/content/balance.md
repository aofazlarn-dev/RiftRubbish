# Balance v2 — ตัวเลขเริ่มต้นสำหรับ MVP (อ้างอิงสเปก gdd_v8 + decisions.md D1–D12)

> สถานะ: **ค่าตั้งต้นก่อน sim** ทุกตัวเลขเป็นสมมติฐานที่ต้องให้ headless sim ยืนยัน (ดู §8) ไม่ได้เปลี่ยนกติกาในสเปกหรือ decisions
> **ไฟล์นี้เป็นแหล่งตัวเลขหลัก (D5)** — HP/ดาเมจ/XP/บอส/งบ DPS; `skills_fusion.md` ใช้ตัวเลขฐานชุดเดียวกับไฟล์นี้ ถ้าขัดกันให้ยึดไฟล์นี้
> v2 (reconcile): บอส HP **5,000** · สกิล 2 ตัวถึง Lv3 ที่ **~5 นาที** (ช้าสุด ~5.9 นาที = ต้นคืน 3) · เส้น Skill XP **50/180/420/800 (+1,050/1,400 สำหรับสกิลผสม, D21)** · DPS อ้างอิง **Active Common Lv1 = 8 DPS เป้าเดี่ยว** · HP มอนรายคืนตาม §5.1

## 0. หน่วยและสมมติฐานพื้นฐาน

- 1 tile = 32 px; แมพ 64×64 tile = 2048×2048 px; ฐานอยู่กลางแมพ (ใน skills_fusion.md เรียก tile ว่า "ช่อง")
- จังหวะ 1 วัน (§4): กลางวัน 70 วิ + เย็น 20 วิ + คืน 40 วิ = **130 วิ**
- ปุ่ม "เรียกคืนเร็ว" (D22): กลางวันกดข้ามเวลาที่เหลือไปตอนเย็นได้ ไม่มีโบนัส · ตารางไทม์ไลน์ด้านล่างคือกรณีไม่กด
- ไทม์ไลน์ (วินาทีนับจากเริ่มกลางวันที่ 1; ก่อนหน้านี้มีฉากเปิด + เลือกสกิลแรก ~15 วิ):

| ช่วง | เริ่ม (วิ) | จบ (วิ) |
|---|---|---|
| กลางวัน 1 / เย็น 1 / คืน 1 | 0 / 70 / 90 | 130 |
| กลางวัน 2 / เย็น 2 / คืน 2 | 130 / 200 / 220 | 260 |
| กลางวัน 3 / เย็น 3 / **ต้นคืน 3** | 260 / 330 / **350** | 390 |
| คืน 4 จบ / คืน 5 จบ / คืน 6 จบ | — | 520 / 650 / 780 |
| กลางวัน 7 + เย็น 7 / คืน 7 (บอส) | 780 / 870 | ~940–960 |

- **ความยาวรอบที่ชนะ (D7: 12–16 นาที)**: ฉากเปิด ~15 + 6 วัน × 130 + กลางวัน/เย็น 7 (90) + บอส (ค่ากลาง ~70 วิ, §3.5) ≈ **955 วิ ≈ 15.9 นาที** → อยู่ในกรอบ · ผู้เล่นเก่งฆ่าบอสเร็ว ~15 นาที · ไม่ถึง 12 นาทีได้เพราะวัน 1–6 จับเวลาตายตัว (ไม่ใช่ปัญหา: กรอบล่างไม่ใช่ข้อบังคับของรอบที่ชนะ)
- **ไม่มีตัวคูณ HP ตามคืน** (ตาม §5): มอนแต่ละชนิดมี HP คงที่ทุกคืน ความยากมาจากชนิดใหม่ ความต้านทานธาตุ affix และจำนวน/สัดส่วน
- "อัตราฆ่า" อ้างอิง: ผู้เล่นค่ากลางฆ่าได้ ~85% ของมอนที่เกิดในคืน, ~70% ของมอนลาดตระเวนกลางวัน, เก็บ XP ได้ ~95% ของที่ดรอป
- XP ที่ดรอปไว้แต่ยังไม่เก็บ ณ รุ่งเช้า → ดูดเข้าตัวอัตโนมัติ (ลดความหงุดหงิดบนมือถือ; มอนที่เหลือยังไม่ให้ XP ตาม §4)

| 9→10 | 40 | 172 | คืน 3 |
| 10→11 | 45 | 217 | คืน 3 |
| 11→12 | 55 | 272 | ปลายคืน 3 / กลางวัน 4 |
| 12→13 | 80 | 352 | คืน 4 |

- ผู้เล่นค่ากลาง: ~Lv9 ก่อนต้นคืน 3 (8 Draft), ~Lv18 ก่อนบอส, จบที่ Lv18–19 → **~17–18 Draft ต่อรอบ** + ใบผสม
- **เลเวลอัพแรก ≤30 วิ**: กลางวัน 1 การันตีกลุ่ม "สไลม์ขยะ" 6 ตัว เกิดห่างจุดเกิด 4–6 tile เดินเข้าหาผู้เล่นทันทีหลังเลือกสกิลแรก (≤15 วิ) — สกิล Lv1 (≈8 DPS) ฆ่าสไลม์ (12 HP) ได้ตัวละ ~1.5 วิ → 5 XP ใน ~10–12 วิ → Lv2 ที่ ~25 วิ
- ข้อตกลงเนื้อหา: **Draft แรก (สกิลแรก) เสนอเฉพาะ Active ที่ไม่ใช่สกิลขยะ** เพื่อให้มีดาเมจพอทำเลเวลอัพแรก ≤30 วิ (ไม่เปลี่ยนกติกา "เลือก 1 จาก 3")

## 2. Skill XP curve

### 2.1 ตาราง (สกิลปกติเพดาน Lv5, สกิลผสมเพดาน Lv7 ตาม D2)

| เลเวลสกิล | Skill XP สะสมที่ต้องมี | ส่วนต่าง | ตัวคูณดาเมจ (เทียบ Lv1) | ใช้กับ |
|---|---|---|---|---|
| Lv1 | 0 | — | ×1.0 | ทุกสกิล |
| Lv2 | 50 | 50 | ×1.25 | ทุกสกิล |
| **Lv3 (ผสมได้)** | **180** | 130 | ×1.55 | ทุกสกิล |
| Lv4 | 420 | 240 | ×1.9 | ทุกสกิล |
| Lv5 | 800 | 380 | ×2.4 | ทุกสกิล (เพดานสกิลปกติ) |
| **Lv6** | **1,050** | 250 | ×2.9 | **สกิลผสมเท่านั้น** (D21) |
| **Lv7** | **1,400** | 350 | ×3.4 | **สกิลผสมเท่านั้น** (เพดาน, D21) |

- สกิลผสมเริ่มที่เลเวลและ SXP ของต้นทางที่สูงกว่า (§7 ข้อ 2) แล้ววิ่งต่อบนเส้นเดียวกัน (D2) → ผสมตอน Lv5 (800) ไปต่อ Lv6 ที่ 1,050
- ส่วนต่าง Lv5→6 (250) ต่ำกว่า Lv4→5 (380) โดยตั้งใจ: สกิลที่ผสมตอน Lv5 (ราวคืน 5–6) มีเวลาเหลือ ~300–350 วิ → Active ได้ ~200 SXP + การ์ดอัพ 1–2 ใบ (+120) ≈ ถึง Lv6 ก่อนบอส (D21) · **Lv7 เป็นเพดานสำหรับผู้เล่นที่โฟกัสสกิลเดียว/ผสมเร็ว** ไม่คาดว่าค่ากลางจะถึง

### 2.2 แหล่ง Skill XP

- **Active (จากการใช้)**: ทุกครั้งที่ร่ายแล้ว **โดนมอนอย่างน้อย 1 ตัว** ได้ Skill XP = คูลดาวน์ของสกิล (วินาที) → ทุกสกิลได้ ~1.0 SXP/วิ เมื่อมีเป้าตลอด ไม่ว่า CD สั้นหรือยาว (ร่ายใส่อากาศไม่ได้ XP)
  - uptime อ้างอิง: คืน ≈ 100%, กลางวัน ≈ 50% (มีแค่มอนลาดตระเวน), เย็น 0% → ~75 SXP/วัน
- **Passive (ตามเวลาติดตั้ง)**: **0.6 SXP/วิ** คงที่ทุกช่วง (รวมเย็น) → ~78 SXP/วัน
- **การ์ด "อัพ" ใน Draft** ให้ **Skill XP** (ไม่ใช่เลเวลตรงๆ เพื่อไม่ข้ามกติกา §6): +40 SXP (สกิล Lv1–2) / +80 (Lv3–4) / +120 (สกิลผสม Lv5–6) — เป็นตัวเร่ง ไม่ใช่ทางหลัก
- ซุปเห็ดเรืองแสง (มื้อเย็น) +30% Skill XP คืนนั้น

### 2.3 การคำนวณ: 2 สกิลถึง Lv3 ภายใน ~5 นาที (§7 ข้อ 6)

สมมติ: สกิล A (Active) ได้ตอนเลือกสกิลแรก t=15, สกิล B (Passive) ได้จากเลเวลอัพแรก t≈25–30

**สกิล A (Active, ไม่มีการ์ดอัพ)**

| ช่วง | วินาที × uptime | SXP สะสม |
|---|---|---|
| กลางวัน 1 (15–70) | 55 × 0.5 = 27.5 | 27.5 |
| คืน 1 | 40 × 1.0 = 40 | 67.5 (Lv2 ระหว่างคืน 1) |
| กลางวัน 2 | 70 × 0.5 = 35 | 102.5 |
| คืน 2 | 40 | 142.5 |
| กลางวัน 3 | 35 | 177.5 |
| ต้นคืน 3 | +2.5 วิ | **180 → Lv3 ที่ t≈352 (≈5.9 นาที)** |

**สกิล B (Passive)**: 180 / 0.6 = 300 วิ → ติดตั้ง t=30 → **Lv3 ที่ t≈330 (≈5.5 นาที, เย็นวันที่ 3)**

**ใส่การ์ดอัพสกิลละ 1 ใบ (+40)** (คาดว่าได้ 2–3 ใบจาก 8 Draft ก่อนคืน 3):
- A: ต้องการ 140 จากการใช้ → ถึงที่ t≈300 (กลางวัน 3)
- B: ต้องการ 140 / 0.6 = 233 วิ → t≈263 (ต้นกลางวัน 3)
- → **ทั้งคู่ Lv3 ที่ ~5 นาที**; กรณีแย่สุด (ไม่ได้การ์ดอัพเลย) ช้าสุดที่ ~5.9 นาที = ต้นคืน 3 ยังผ่านเป้า §7 ข้อ 6
- ใบผสมโผล่เป็นใบที่ 4 ใน Draft ถัดไป — คืน 3 ผู้เล่นเลเวลอัพทุก ~10–15 วิ จึงเห็นใบผสมภายในคืน 3
- โอกาส "ถือคู่สูตร" ถูกช่วยด้วย Draft bias ×2 (D10, §9)

**ช่วงท้าย**: Active ~75 SXP/วัน → สกิลแรก Lv4 ราวคืน 5–6; Lv5 ต้องใช้การ์ดอัพ → ผู้เล่นที่โฟกัสได้ Lv5 1–2 สกิลก่อนบอส · สกิลผสมที่เกิดคืน 3 (Lv3, 180) ถึง Lv4 ราวคืน 5 และ Lv4–5 ตอนบอส

## 3. มอน

### 3.1 หลักความต้านทาน

- ธาตุ = tag ไฟ / น้ำแข็ง / สายฟ้า / ดิน / เงา (tag "สัตว์" เป็นสาย summon ไม่มีความต้านทาน; สกิลไม่มี tag = "กายภาพ")
- อ่อน = รับดาเมจ ×1.5, ต้าน 50% = ×0.5, ต้าน 75% = ×0.25 · ต้านสูงสุด 75% (ไม่มีภูมิคุ้มกัน 100%)
- เงื่อนไขออกแบบ: **ทุกคืนมีมอนอย่างน้อย 2 ชนิดที่ไม่ต้านธาตุใดๆ** เพื่อไม่ให้ build ธาตุเดียวตันทั้งคืน

### 3.3 พฤติกรรม (steering ตรงเข้าหา ตามสเปก §12)

1. **สไลม์ขยะ** — เดินหาผู้เล่นถ้าอยู่ใน 8 tile ไม่อย่างนั้นเดินหาแกน · มอนเติมจำนวน/ฝึกมือ
2. **ค้างคาวรอยแยก** — ล่าผู้เล่นอย่างเดียว บินซิกแซก (เบี่ยง ±30° ทุก 0.5 วิ) โดนตีแล้วถอย 0.5 วิ · กดดันให้ขยับ
3. **ก็อบลินขโมยหม้อ** — **มุ่งแกนฐาน** ไม่สนผู้เล่น ยกเว้นผู้เล่นอยู่ใน 2 tile หรือตีมันใน 2 วิที่ผ่านมา · บังคับให้ผู้เล่นกลับมาปกป้องฐาน
4. **โครงกระดูกนักธนู** — รักษาระยะ 5–7 tile ยิงผู้เล่นทุก 2 วิ (ลูกธนู 200 px/s มีเส้นเตือน 0.3 วิ) ถ้าผู้เล่นห่างแกนเกิน 10 tile จะยิงแกนแทน · ลงโทษการยืนนิ่ง
5. **โกเลมโคลน** — มุ่งแกน ช้า ไม่โดน knockback, CC เหลือ 50% ของระยะเวลา · "กระสอบทราย" วัด DPS เดี่ยว
6. **วิญญาณหมอก** — เกิดจาก **ขอบหมอก** (ไม่ใช่วงเกิดปกติ) ทะลุสิ่งกีดขวาง ทุก 5 วิ อมตะ 1 วิ (มีสัญญาณจางลง 0.5 วิก่อน) เป้า = ผู้เล่น · ลงโทษ build กายภาพล้วน

- เป้า: ค่ากลาง (DPS เป้าเดี่ยวคืน 4 ~45) ใช้ ~15 วิแท้ๆ บวกเวลาไล่/หลบพุ่ง/ร่างแยก → **ฆ่าได้ภายในคืน 4 ราว 50–65%** ที่เหลือล่าในกลางวัน 5 (เป้า Core ถึงมือ ≥90% ของผู้เล่นที่รอดถึงกลางวัน 5)

## 4. Affix (Elite/มอนช่วงท้าย)

ใช้กับมอนปกติตั้งแต่คืน 5 (โอกาส: คืน 5 = 10%, คืน 6 = 20%, คืน 7 = 25%) และผู้เฝ้าหีบเสี่ยงกลางวัน 5–7; มอนติดได้สูงสุด 1 affix · มอนมี affix ใหญ่ขึ้น 20% + ขอบสีม่วงรอยแยก · **XP ×2**

| # | ชื่อ | ผล | ตัวสวน |
|---|---|---|---|
| 1 | **เร่งรีบ** | ความเร็ว +40% | slow/CC, AoE ดักทาง |
| 2 | **เกราะขยะ** | โล่ = 50% ของ HP ต้องตีโล่ก่อน; โล่ฟื้นเต็มถ้าไม่โดนตี 5 วิ | DPS ต่อเนื่อง |
| 3 | **ระเบิดตอนตาย** | ตายแล้วระเบิดหลัง 1.0 วิ r=64 px: ผู้เล่น 12, แกน 20 | ฆ่าให้ไกลฐาน, ระยะไกล |
| 4 | **ต้านทางเลือก** | ต้าน 50% ต่อ tag ธาตุที่ผู้เล่นมีมากที่สุดตอนมอนเกิด (เสมอกัน = สุ่ม) | build 2 ธาตุ / กายภาพ |
| 5 | **จ่าฝูง** | ออร่า r=96 px: มอนรอบตัว ความเร็ว +20%, ดาเมจ +20% (ไม่ซ้อน) | เล็งฆ่าจ่าก่อน |

- กติกากันหงุดหงิด: affix 4 ห้ามซ้อนกับความต้านทานโดยกำเนิดเกิน 75% · affix 3 ไม่โซ่ต่อกัน (ระเบิดไม่จุดระเบิดตัวอื่น)
- ประมาณ HP มีผล (effective HP) เพิ่ม ~+50% ต่อมอนที่มี affix (ใช้ในตาราง wave)

### 5.4 DPS โดยประมาณของ build ค่ากลาง ต่อคืน เทียบ DPS ที่ต้องมี

**วิธีคิด**
- **DPS ที่ต้องมี** = (HP มีผลมอนปกติ × 0.85 + HP Elite/ร่างแยก × 0.9; คืน 4 ใช้ × 0.6 ตาม D21) ÷ 40 วิ × **ตัวคูณความต้านทาน** (build ค่ากลาง 2 ธาตุเจอมอนที่ต้าน: คืน 3 ×1.05 · คืน 4 ×1.10 · คืน 5–6 ×1.20) — คือ DPS ที่ทำให้ฆ่าได้ ~85% แกนเสียไม่เกินงบ = "ตึงแต่ผ่าน"
  - คืน 7 = บอส 5,000 ÷ 80 วิ (เป้าเดี่ยว) + พื้นหลัง ~24 × 1.1
- **DPS ค่ากลาง** = Σ(Active ตาม §5.3) × ส่วนผสม AoE ของ build (กลางคืน ×1.2, บนบอส ×0.8) × **ประสิทธิภาพจริง 0.7** (overkill, เป้าหลุดระยะ, เดินกลับฐาน) × (1 + Σ Passive) × อาหาร/อื่นๆ ×1.10
  - "อาหาร ×1.10" = ค่ากลางของบัฟมื้อเย็น (สตู +15% / ข้าวกล่อง +8% / บางคืนกินสายอื่น); synergy ขั้น 2 ส่วนใหญ่เป็นผลรอง ไม่นับ
- ตัวย่อ: C/R/E = Common/Rare/Epic, J = สกิลขยะ, F = สกิลผสม, ตัวเลข = เลเวล (2.5 = ระหว่าง Lv2→3), (½) = มีแค่ครึ่งคืน

|---|---|---|---|---|---|---|---|---|
| 1 | C1.5, C1 (½) · P C1 (+ อุกกาบาตทดลอง) | 13.8 | ×1.06 | **~22** (ไม่มีอุกกาบาต ~13) | **~10** | 0.45 (Daily 0.70) | — | แทบไม่มีใครตาย |
| 2 | C2, C1.5, J1.5, R1 (½) · P C1.5, J1 | 28.2 | ×1.13 | **~30** | **~20** | 0.68 | — | เรียนป้องกันแกน |
| 3 | C2.5, C2, R1.5, J3→ผสมกลางคืน F-Epic3 · P C2, J1.5 (J ถูกผสม) | 48.5 | ×1.16 | **~52** | **~31** | 0.59 | — | ผสมครั้งแรก รู้สึกเทพ |
| 4 | F-Epic3, C3, C2.5, R2 · P 2.5, 2, 1 | 59.0 | ×1.24 | **~68** | **~49** (Elite ×0.6 ตาม D21; เดิม ~57, Elite เป้าเดี่ยว ≥15) | 0.72 | ~45 | ด่านทดสอบแรก |
| 5 | F-Epic3.5, C3, C3, R2.5 · P 3, 2.5, 1.5, 1 | 64.2 | ×1.34 | **~80** | **~67** | 0.85 | ~53 | ทดสอบธาตุ (ตายสูงสุด) |
| 6 | F-Epic3.5, F-Epic3 (ผสมครั้งที่ 2), C3, R2.5 · P 3.5, 2.5, 2, 1 | 75.2 | ×1.37 | **~95** | **~85** | 0.90 | ~63 | โหดสุดก่อนบอส |
| 7 | F-Epic4, F-Epic3.5, C3, R3 · P 3.5, 3, 2, 1.5 | 81.9 | ×1.39 | **~105** | **~89** (บอส ~63 + พื้นหลัง ~26) | 0.85 | **~70 → บอสตาย ~71 วิ** | ฆ่าก่อน enrage ถ้าอยู่ที่ค่ากลาง |

## 6. แกนฐาน มื้อเย็น และทางเลือกเย็นนี้

### 6.1 แกนฐาน

| ค่า | ตัวเลข |
|---|---|
| Max HP | **1,000** |
| ผู้เล่นตาย | −15% = −150 (ตาม §5) |
| ซ่อมอัตโนมัติตอนรุ่งเช้า | +10% (100) |
| ซ่อมด้วยมือ (กลางวัน/เย็น ยืนที่แกน) | วัตถุดิบไม้/หิน 1 ชิ้น = +30 HP, 0.5 วิ/ชิ้น |
| ดาเมจมอนต่อแกน | ดูคอลัมน์ "ดาเมจต่อแกน" ใน §3.2 (มอนตีทุก 1 วิ ยกเว้นระบุ) |

**งบดาเมจแกนต่อคืน (ผู้เล่นค่ากลาง, ไม่ตาย)**

| คืน | แกนเสีย | หลังซ่อม (รุ่งเช้า + มือ ~5 ชิ้น) |
|---|---|---|
| 1 | 0–5% | 100% |
| 2 | ~8% | 100% |
| 3 | ~12% | ~100% |
| 4 | ~20% | ~90% |
| 5 | ~25% | ~80% |
| 6 | ~30% | ~65% |
| 7 | บอสถึงแกน ~25 HP/วิ (หลัง enrage) → ~25 วิจากแกน 65% ถึงพัง | — |

- เส้นตาย: ผู้เล่นค่ากลางตาย 1 ครั้งต่อคืนในคืน 5–6 (−15%) = ไปถึงคืน 7 ด้วยแกน ~35–50% → บอสต้องตายก่อน/ราว enrage

### 6.2 มื้อเย็น (Casual: กินวันละ 1 ครั้ง, บัฟคืนนั้น)

วัตถุดิบ: ธัญพืช, เห็ด (เก็บตามแมพ), น้ำ, ปลา (บ่อน้ำ — seed มีบ่อใกล้จุดเกิดตาม §4), เนื้อสด (ดรอปจากมอน 3%) · เก็บได้ ~5–7 ชิ้น/วันถ้าใช้เวลาเก็บ ~20 วิ

| # | อาหาร | สูตร | บัฟคืนนั้น | บทบาท |
|---|---|---|---|---|
| 1 | ขนมปังแข็งโป๊ก | ธัญพืช 2 | Max HP +20% | ง่ายสุด กันตาย |
| 2 | สตูเนื้อมอน | เนื้อสด 1 + น้ำ 1 | ดาเมจ +15% | สายบุก |
| 3 | ปลาย่างบ่อน้ำ | ปลา 1 + น้ำ 1 | ความเร็ว +12%, ระยะเก็บของ +40% | สายเก็บ/คุมพื้นที่ |
| 4 | ซุปเห็ดเรืองแสง | เห็ด 2 + น้ำ 1 | Skill XP +30% | สายเร่งผสม (คืน 2–3) |
| 5 | ข้าวกล่องต่างโลก | ธัญพืช 1 + เห็ด 1 + เนื้อสด 1 | ดาเมจ +8%, คูลดาวน์ −8%, ฟื้น HP 0.5/วิ | ดีรอบด้าน หายาก |

**ดีบัฟเมื่อไม่ได้กิน — "หิวจนตาลาย"** (คืนนั้น): ดาเมจ −15%, ความเร็ว −10%, ไม่ได้ฟื้น HP จากเนื้อสด

- ช่องว่างระหว่างกินดี (+15%) กับไม่กิน (−15%) ≈ 30% DPS → มากกว่าส่วนเผื่อของคืน 4–6 (10–15% ตาม §5.4) จึงตั้งใจให้ "ไม่กิน" ในคืน 5–6 = เสี่ยงตายสูง

### 6.3 ทางเลือกเย็นนี้ (1 จาก 3, ตาม §4 + D9)

| ทางเลือก | ราคา | ผล | หมายเหตุ |
|---|---|---|---|
| **รั้วขยะ** | อาหารสำรอง 1 ชิ้น (= อาหารที่ทำแล้ว 1 จาน นอกเหนือจากที่กินมื้อเย็น) | **โล่ให้แกนฐาน = 30% ของ Max HP (= 300) เฉพาะคืนนั้น** โดนก่อนเนื้อแกน หายตอนรุ่งเช้า (D9) | เลือกซ้ำได้ทุกคืน (โล่ไม่ซ้อนข้ามคืน) · ค่าเท่ากับงบแกนเสียคืน 6 ทั้งคืน |
| **กับดักสะดุดล้ม** | — (ฟรี) | วางกับดัก 6 อันรอบฐาน (r = 4 tile) อันละ 3 ครั้ง: มอนล้ม 2 วิ; ผู้เล่นเหยียบก็ล้ม 1.5 วิ | ไม่ซ้อนกับผลล้มของสกิล "สะดุดล้ม" (ใช้ระยะเวลาที่ยาวกว่า) · UI ใช้ไอคอนกับดักแยกจากไอคอนสกิล |
| **ทำโอทีกะดึก** / Unpaid Overtime | คืนนั้นไม่ได้มื้อเย็น (ติด "หิวจนตาลาย") | **เปิดตั้งแต่เย็นวันที่ 4** · **Soul Shard +20% ของทั้งรอบ** (คิดตอนจบรอบ หลังตัวคูณชนะ/แพ้/ยอมแพ้) | **เลือกได้ครั้งเดียวต่อรอบ** (D9, D18) — หลังเลือกแล้วการ์ดนี้ไม่โผล่อีก · ไม่มีในโหมด Daily (§2) · ได้ Shard แม้แพ้ · ชื่อเปลี่ยนจาก "ขายวิญญาณ" (D24) |

- มูลค่าทำโอที: รอบแพ้ค่ากลาง (~20 Shard) ได้ +4; รอบชนะ (~120+) ได้ +24 → คุ้มเฉพาะเมื่อมั่นใจว่ารอด = การเดิมพันที่ตั้งใจ · เปิดได้ตั้งแต่เย็นวันที่ 4 (สัดส่วน DPS คืน 4 ~0.72 ก่อนหิว, ~0.93 ถ้าหิว = ตึง) · คืน 5–6 ที่หิวเสี่ยงตายสูง (§5.4)

## 7. เป้าความยาก

| เมตริก | เป้า |
|---|---|
| อัตราชนะรอบแรก (Casual, ไม่มี meta) | **~20–25%** (D8) |
| จบรอบแรก (เล่นจนชนะหรือแพ้ ไม่ปิดกลางคัน) | **≥40%** (D8 — วัดจาก run_end ต่อ run_start ของรอบแรก) |
| การกระจายคืนที่ตาย (รอบแรก) | คืน 1–2: 5% · คืน 3: 8% · คืน 4: 15% · **คืน 5: 20%** · คืน 6: 17% · คืน 7: 12% · ชนะ ~23% |
| คืนที่คนส่วนใหญ่ควรตาย | **คืน 5–6** (ช่วงคืน 4–6 รวม ~50%) — ไม่มีคืนเดียวเกิน 50% ตามเกณฑ์ playtest |
| ผสมเองครั้งแรก | ≥60% ของผู้เล่นภายในคืน 3 (ตามเกณฑ์ playtest; ช่วยด้วย Draft bias D10) |
| ได้ Fusion Core จาก Elite | ≥90% ของผู้เล่นที่รอดถึงกลางวัน 5 (D6) |
| รอบที่คาดว่าจะชนะครั้งแรก | **รอบที่ 2–3** (ค่ากลางรอบ 3) จากความเข้าใจระบบ + meta ชิ้นแรก |
| ระยะเวลารอบที่ชนะ | **12–16 นาที** (D7) — คำนวณได้ ~15–16 นาที (§0) |

**Shard จากรอบแพ้ค่ากลาง** (ตายคืน 5 = รอด 4 คืน): (5+7+9+11) × 0.5 = 16 + ภารกิจ ~4 → **~20 Shard/รอบ** · ข้อเสนอ: ปลดล็อกชิ้นแรก (ชาติก่อน 1 อาชีพ) ราคา ~35–40 → ได้หลังรอบที่ 2 → ช่วยให้รอบ 3 ชนะ

**กฎ meta/โหมด (D18–D19):** ภารกิจรายวันข้อละ ≤5 Shard ผ่านตัวคูณเดียวกับ Shard อื่น · meta ทุกชิ้นรวมกันไม่เกิน +15% พลังเทียบเท่า (ชิ้นละ ~+5%) · ยอมแพ้ ×0.5 = เท่ากับแพ้ · Daily นับเฉพาะการเล่นจบครั้งแรกของวัน (ครั้งต่อไปป้าย "ซ้อม") · รอบจาก `?seed=` ไม่ได้ Shard · import save ได้จากเมนูหลักเท่านั้น (รอบค้างนับเป็นยอมแพ้)

## 8. ตัวเลขที่ต้องยืนยันด้วย headless sim (เสี่ยงที่สุด 5 ข้อ)

1. **เวลาถึง Lv3 ของ 2 สกิล + โอกาสถือคู่สูตร** — uptime Active กลางวัน 50%, Passive 0.6/วิ, การ์ดอัพ +40 → ต้องได้ Lv3 ทั้งคู่ที่ ≤350 วิ **และ** ถือคู่สูตร (10 สูตร, Draft bias ×2) — วัด % รอบที่ผสมได้ภายในคืน 3 (เป้า ≥60%) ด้วยบอทเลือกแบบสุ่มและแบบโลภ
2. **เส้น DPS ค่ากลาง vs DPS ที่ต้องมี (§5.4)** — สมมติฐานใหญ่สุด: ประสิทธิภาพจริง 0.7, ส่วนผสม AoE ×1.2, Passive +6%/ตัว, โบนัสผสม ×1.3 · ถ้าคลาด 15% สัดส่วนคืน 4–6 (0.84–0.90) จะกลายเป็น "ตายหมู่" หรือ "ง่ายเกิน" · วัด: % HP ที่ฆ่าได้ต่อคืน, แกนเสียต่อคืน
3. **บอส 5,000 vs DPS เป้าเดี่ยว ~70** — ค่ากลางต้องฆ่าได้ ~65–80 วิ; ตรวจด้วยว่า AoE build ไม่ตันบนบอส (อัตราส่วนเป้าเดี่ยว/มีผล ~0.67) และความยาวรอบชนะ ≤16 นาที (D7)
4. **เพดาน 40 ตัว + คิวเกิด** — คืน 5–6 เกิด 1.9–2 ตัว/วิ ถ้าฆ่าช้าจะติดเพดาน มอนที่ไม่ได้เกิดจะหายตอนรุ่งเช้า → XP/แรงกดดันจริงอาจต่ำกว่าตาราง ต้องวัดจำนวนที่เกิดจริงและ XP ที่ได้จริงเทียบ curve §1.2
5. **เศรษฐกิจแกนฐาน** — ดาเมจต่อแกนของก็อบลิน/โกเลม, ซ่อมรุ่งเช้า +10%, ซ่อมมือ 30 HP/ชิ้น, ผู้เล่นตาย −15%, รั้วขยะ 300 → ต้องได้แกน ~35–65% ตอนเข้าคืน 7

(รองลงมา: % ฆ่า Elite ในคืน 4 (เป้า 50–65%) และ % ได้ Core, ช่องว่างกิน/ไม่กิน 30%, กลุ่มสไลม์การันตีทำให้ Lv2 ≤30 วิจริงไหมบนมือถือ, % รอบที่ถึงสกิลผสม Lv6, สาเหตุการตายจากอุกกาบาตตกใส่ตัวเอง, pick rate synergy ดิน 6)

## 9. Skill Draft (D3, D4, D10)

### 9.1 ตารางความหายากของ Draft ใน MVP (D3 — แทน §6 ของสเปกสำหรับ MVP)

| ความหายาก | % ต่อการ์ด | สกิลใน pool เริ่มต้น |
|---|---|---|
| Common | **55** | 5 สาย + 6 ขยะ = 11 |
| Rare | **28** | 4 |
| Epic | **12** | 2 |
| Legendary | **5** | 1 |
| Mythic | **0** (ได้จากสูตรผสม F09 เท่านั้น) | 0 |

- Fusion Core "ดันความหายาก +1" **มีเพดานที่ Legendary** (D3)
- สกิลต้นทางที่ถูกผสมไปแล้วกลับเข้า pool ได้ (D4) → สูตรเดิมผสมซ้ำได้ถ้าถือคู่ครบอีกครั้ง
- ถ้าความหายากที่สุ่มได้ไม่มีสกิลที่ยังเสนอได้ (เช่น Legendary 1 ตัวที่ถืออยู่แล้ว) → ลดลง 1 ขั้นจนเจอ

### 9.2 ลำดับการสุ่มการ์ด 1 ใบ

1. สุ่มความหายากตาม 9.1
2. ในความหายากนั้น สุ่มสกิลแบบถ่วงน้ำหนัก: น้ำหนักฐาน 1
3. **Draft bias (D10)**: สกิลที่ **จะครบคู่สูตรกับสกิลที่ถืออยู่** (ไม่สนเลเวล) ได้น้ำหนัก **×2** · ไม่ซ้อน (ครบได้ 2 สูตรก็ยัง ×2) · ไม่ใช้กับสกิลที่ถืออยู่แล้ว (การ์ด "อัพ" ไม่ได้ bias)
4. ใบการันตี synergy tag (สเปก §6) สุ่มเฉพาะใน pool ที่มี tag ตรง แล้วใช้ bias ข้อ 3 เหมือนกัน
5. ใบผสมเป็น **ใบที่ 4** แยก (§7) ไม่ผ่านการสุ่มนี้ — ถ้ามีหลายคู่เข้าเงื่อนไขพร้อมกัน แสดงคู่ที่ผลลัพธ์ความหายากสูงสุด (เท่ากัน = คู่ที่เข้าเงื่อนไขก่อน) คู่อื่นรอ Draft ถัดไป
6. การ์ดผสมแสดงพรีวิวผลที่จะได้ + สกิลที่ต้องดันให้สูงกว่าเพื่อได้อีกผล (D1) + ผลต่อ synergy tag

ผลคาดการณ์ (ให้ sim ยืนยัน): ถือสกิลที่อยู่ในสูตร 2–3 ตัว ณ กลางวัน 2 → bias ×2 เพิ่มโอกาสเจอคู่ใน Draft 4–5 ใบก่อนคืน 3 จาก ~45% เป็น ~65%

## ข้อสังเกตถึงทีม (ยังเปิดอยู่)

1. **เวลาจริงของรอบกับ D7**: ตัวเลขเวลาเกม ~15–16 นาที (§0) ไม่นับเวลาที่เกมหยุดตอนเลือก Draft/ใบผสม/อีเวนต์ (~18 Draft × 2–4 วิ ≈ +1 นาที) — ถ้า D7 นับเวลาจริง รอบที่ชนะจะ ~17 นาที ต้องตัดสินว่า D7 นับเวลาเกมหรือเวลาจริง (ถ้าเวลาจริง ตัวเลือกที่ไม่แตะกติกาคือเร่งบอสให้ตายเร็วขึ้น เช่น HP 4,200 แต่จะทำให้คืน 7 ไม่ตึง)
2. **Fusion Core — ปิดแล้วตาม D17**: ใช้ตอนกดใบผสมได้ (+1 ขั้นความหายาก เพดาน Legendary) · Elite ให้ 1 ลูกแน่นอนสำหรับ F09 · ลูกเพิ่มจากหีบเสี่ยงกลางวัน 5–7 (5%) ไม่เกิน 1 ลูก/รอบ
3. **R01a ใน Casual — ปิดแล้วตาม D15**: หยุดร่ายเองเมื่อ HP ≤20% (Hardcore ไม่หยุด) · สาเหตุการตายยังต้องให้ playtest/sim ยืนยัน
