# การตัดสินใจของ Design Lead (Phase 2, ร่าง 1) — มีผลเหนือ gdd_v8.md และไฟล์เนื้อหา

D1. การ์ดผสมใบที่ 4 แสดงพรีวิวผลที่จะได้ + บอกว่า "ดันสกิลไหนให้สูงกว่าเพื่อได้อีกผล"
D2. สกิลผสมมีเพดาน Lv7 (สกิลปกติ Lv5) เพื่อให้ผสมตอน Lv5 แล้วยังโตต่อได้; ใช้เส้น Skill XP ต่อจาก Lv5
D3. MVP ไม่มีสกิล Mythic ใน pool ของ Draft → ตารางความหายากของ Draft ใน MVP = Common 55 / Rare 28 / Epic 12 / Legendary 5 (Mythic ได้จากสูตรผสมเท่านั้น) · Fusion Core "ดันความหายาก +1" มีเพดานที่ Legendary
D4. สกิลต้นทางที่ถูกผสมไปแล้วกลับมาโผล่ใน Draft ได้
D5. ไฟล์ balance.md เป็นแหล่งตัวเลขหลัก (HP/ดาเมจ/XP/บอส); skills_fusion.md ต้องใช้ตัวเลขฐานเดียวกัน — ตอนนี้ขัดกัน (บอส 5,000 vs 12,000; Lv3 ~5 นาที vs 3–4 นาที) ต้อง reconcile
D6. Elite หมาป่ามิติ (คืน 4) ไม่ถูกหมอกดูดตอนรุ่งเช้า ถ้ายังไม่ตายจะหนีไปซ่อนที่รังบนแผนที่ (แสดงบน minimap) ล่าต่อกลางวันได้ ดรอป Fusion Core เมื่อตาย
D7. เป้าความยาวรอบที่ชนะ: 12–16 นาที (แก้จาก 10–15)
D8. "จบรอบแรก ≥40%" = เล่นจนจบรอบ (ชนะหรือแพ้) ไม่ปิดกลางคัน; เป้าชนะรอบแรก 20–25%
D9. รั้วขยะ = โล่ให้แกนฐาน +30% ของ HP สูงสุดเฉพาะคืนนั้น; ขายวิญญาณ = Shard +10% ของทั้งรอบ เลือกได้ครั้งเดียวต่อรอบ และคืนนั้นไม่ได้มื้อเย็น (ติดดีบัฟหิว)
D10. Draft bias: สกิลที่จะครบคู่สูตรกับสกิลที่ถืออยู่ได้น้ำหนัก ×2 ในการสุ่ม
D11. ภารกิจรายวันจากระบบ วันละ 3 ข้อ (Casual เท่านั้น)
D12. สะดุดล้มยังเป็น Passive (ผลอุกกาบาต vs แผ่นดินไหว ขึ้นกับการดันเลเวลตามกติกา) — พรีวิวตาม D1 แก้ปัญหาความคาดหวังจาก tutorial
D13. ความยาวรอบ D7 นับเป็นเวลาเกม (ไม่รวมช่วงหยุดเลือก Draft); เวลาจริงยอมรับได้ ≤18 นาที
D14. Fusion Core: ใช้ตอนกดการ์ดผสมเพื่อดันความหายาก +1 (เพดาน Legendary) หรือใช้ในสูตร Mythic; แหล่งได้มา = Elite คืน 4 (แน่นอน) + หีบเสี่ยงกลางวันมีโอกาส 15%
D15. อุกกาบาตตกใส่ตัวเอง: ในโหมด Casual หยุดร่ายเองอัตโนมัติเมื่อ HP ≤20% (Hardcore ไม่หยุด)

## ชุดตัดสินใจหลังรีวิว P2 รอบ 1 (Balance 6.5, Red team 4, Dev 6, ผู้เล่นใหม่ 8/8)
D16. R09b "ข้าคือเงา": ก๊อป Active ที่ 40% คงที่ ไม่โตตามเลเวล · ห้ามก๊อป R01a อุกกาบาต · สลับร่างอมตะได้คืนละ 1 ครั้ง · รัง Elite ตรวจจับ 11 tile (ไกลกว่าระยะสกิลสูงสุด 10) กันยิงจากนอกระยะ
D17. Fusion Core: หีบเสี่ยงดรอป 5% เฉพาะกลางวันที่ 5–7 ได้จากหีบไม่เกิน 1 ลูก/รอบ · ตัด Core ออกจาก EV6 · รวมแล้ว 1 ลูกแน่นอน (Elite) + โอกาสอีกไม่เกิน 1 · ดันความหายาก +1 = ตัวคูณขั้นความหายากตาม balance (Epic→Legendary ≈ ×1.21)
D18. เศรษฐกิจ Shard: ทางเลือก "ขายวิญญาณ" (เปลี่ยนชื่อ ดู D24) เปิดตั้งแต่เย็นวันที่ 4, +20% ของ Shard ทั้งรอบ, ครั้งเดียว/รอบ · ยอมแพ้ ×0.5 เท่ากับแพ้ (แทน ×0.6) · ภารกิจรายวันข้อละ ≤5 Shard และผ่านตัวคูณเดียวกับ Shard อื่น · meta ทุกชิ้นรวมกันไม่เกิน +15% พลังเทียบเท่า (ชิ้นละ ~+5%)
D19. Save/Seed: import save ได้จากเมนูหลักเท่านั้น และรอบที่ค้างอยู่นับเป็นยอมแพ้ · Daily: นับเฉพาะครั้งแรกที่เล่นจบในวันนั้น ครั้งต่อไปติดป้าย "ซ้อม" บนการ์ดแชร์ · รอบที่เปิดจากลิงก์ ?seed= เล่นได้แต่ไม่ได้ Shard
D20. ธาตุ: วิญญาณหมอก เปลี่ยนเป็นต้านไฟ 50% · โครงกระดูก เปลี่ยนเป็นอ่อนเงา · ค้างคาว ไม่ต้านเงา
D21. ตัวเลข: R03b dot 1/วิ/stack, รีเซ็ต stack หลังระเบิด, ระเบิด 20, คูลดาวน์ต่อเป้า 4 วิ · R02b เผา 7/วิ, ฟื้น 0.5 HP/วิ · F07, F08 ผลเป็น Epic · Skill XP Lv6 = 1,050, Lv7 = 1,400 · แก้ผลรวม HP คืน 7 = 2,300 · สูตรคืน 4 ใช้อัตราฆ่า Elite 0.6
D22. ปุ่ม "เรียกคืนเร็ว": กลางวันกดข้ามเวลาที่เหลือไปตอนเย็นได้ (ไม่มีโบนัส ไม่เสียอะไรนอกจากเวลาเก็บของ) ลดช่วงน่าเบื่อคืน 1–3 สำหรับคนเล่นเก่ง
D23.
