# Rift & Rubbish: System Error — สเปกฉบับสุดท้าย v8 (ผ่านการตรวจรับ — ใช้แทนทุกเวอร์ชันก่อน)

## 1. ภาพรวม
- Survivor-like + survival เบาๆ แนว isekai, 2D top-down บน browser (PC + มือถือ), single-player. ผู้สร้างทำคนเดียวช่วงเวลาว่าง (Phaser 3 + TypeScript)
- Positioning: "Vampire Survivors ที่ evolution มาจากสกิลขยะ + มีกลางวันให้เอาตัวรอด + ระบบปากแซ่บแบบนิยาย isekai"
- Hook: "เกิดใหม่พร้อมสกิลขยะ เอามาผสมให้เทพ แล้วรอดให้ครบ 7 คืน"

## 2. โหมด (วันเปิดตัว itch.io)
- **รอด 7 คืน (Casual)** — โหมดหลัก 10–15 นาที จบด้วยบอสจันทร์เลือดคืนที่ 7
- **Daily Seed** — ทุกคนได้ seed เดียวกัน, loadout ตายตัว, ปิด meta/Fate Shard, ไม่มี "ขายวิญญาณ", ผลแชร์เป็นอีโมจิแบบ Wordle (ไม่มี leaderboard ออนไลน์ในวันเปิดตัว)
- **Hardcore Lite (เบต้า) = อัปเดต 1 (~2 สัปดาห์หลังเปิดตัว)** — หิว/น้ำต่อเนื่อง, ปิด auto-aim (มือถือ twin-stick) และ auto-pickup, ไม่ได้ Shard โบนัส. วันเปิดตัวเมนูแสดงปุ่ม "Hardcore — มาในอัปเดต 1" (ล็อก) ให้คนสาย hardcore รู้ว่ามี; ทดสอบ twin-stick มือถือใน vertical slice
- อัปเดต 2 (หลังมี metrics): Hardcore เต็ม (อุณหภูมิ, อาหารเน่า, น้ำหนักกระเป๋า, Shard ×1.5, ชาติก่อน "นักล่า", สูตรลับอาหารเน่า) + "คำสาปของระบบ" Lv1–5

## 3. 30 วินาทีแรก
0–5 วิ ฉากตาย (รถบรรทุกชน) + ระบบแซว → ≤15 วิ เลือกสกิลแรก 1 จาก 3 → ≤30 วิ เลเวลอัพแรก → ต้นคืนที่ 1 อีเวนต์ระบบ "ของขวัญต้อนรับ" (เฉพาะโหมด Casual ทุกรอบ, Daily ไม่มี): ยัดสกิลขยะคู่สูตร (สะดุดล้ม + ขว้างหิน) เป็นสกิลชั่วคราวนอกช่อง แล้วเปิดหน้าผสมแบบบังคับ (การ์ดใบเดียว กดผสมเท่านั้น) → ได้ "อุกกาบาตตกใส่ตัวเอง" Lv1 ล็อกเลเวล เป็นสกิลชั่วคราวนอกช่อง ใช้ได้ถึงรุ่งเช้าคืนที่ 1 แล้วหายไป ระบบแซว "ทดลองใช้ฟรีหมดแล้ว อยากได้ก็ผสมเองสิ" (tutorial นี้ไม่ใช้กติกา Fusion ข้อ 1–3)

## 4. จังหวะ 1 วัน (≈2 นาที)
- กลางวัน 70 วิ: สำรวจแมพ 64×64, มอนลาดตระเวน, หีบเสี่ยง, อีเวนต์สุ่ม, เก็บวัตถุดิบ (auto-pickup), คราฟต์ของพื้นฐานได้ทุกที่
- เย็น 20 วิ: กลับฐาน, **มื้อเย็น** (Casual: กินวันละครั้ง เลือกบัฟของคืนนั้น ไม่มีอาหาร = ดีบัฟ), **ทางเลือกเย็นนี้** 1 จาก 3 ที่มีราคา (รั้วขยะ: จ่ายอาหารสำรอง 1 ชิ้น แกนฐาน +30% HP; กับดักสะดุดล้ม: มอนล้ม 2 วิ แต่เราก็ล้มได้; ขายวิญญาณ: Shard +10% แต่คืนนี้ไม่ได้มื้อเย็น)
- คืน 1–6: 40 วิ จบเมื่อหมดเวลา; รุ่งเช้ามอนที่เหลือถูกหมอกดูดกลับ (ไม่ได้ XP)
- คืน 7 (จันทร์เลือด): ไม่จับเวลา บอสเกิดต้นคืน enrage เมื่อครบ 90 วิหลังเกิด (ค่าตั้งต้น: ดาเมจ ×1.5, ความเร็ว ×1.3, เรียกมอนลูกน้อง 5 ตัวทุก 15 วิ — จูนจาก sim) คืนจบเมื่อบอสตาย (ชนะ) หรือแกนฐานพัง (แพ้)
- หมอกมิติหดคืนละ 10% ของรัศมี ทรัพยากรเกิดใหม่ที่ขอบหมอก; seed ต้องมีบ่อน้ำใกล้จุดเกิด

## 5. ชนะ/แพ้
- แกนฐาน HP 0 = แพ้. ผู้เล่น HP 0 = ฟื้นที่ฐานใน 10 วิ แกนฐานเสีย 15%
- Elite คืน 4 "หมาป่ามิติ" แยกร่างทุก 25% HP ดรอป Fusion Core แน่นอน
- ความยากเพิ่มด้วยชนิดมอนใหม่ ความต้านทานธาตุ และ affix (ไม่ใช่เพิ่มเลือดเส้นตรง); ตัวเลข wave มาจาก sim; มอนบนจอสูงสุด 40 (มือถือสเปกต่ำ, fallback 30fps)

## 6. สกิล
- 6 สาย (นักรบ, ธาตุ, ผู้เอาตัวรอด, ช่าง, ผู้เรียก, จิต) + "สกิลขยะ" (เตะฝุ่น, สะดุดล้ม, ขว้างหิน, จุดไฟติดยาก ฯลฯ); Synergy tags (ไฟ, น้ำแข็ง, สายฟ้า, สัตว์, ดิน, เงา) ครบ 2/4/6 ได้โบนัส
- ช่อง Active 4 + Passive 4. เลเวลสกิลจาก Skill XP (Active จากการใช้, Passive ตามเวลาที่ติดตั้ง)
- **Skill Draft** ทุกเลเวลอัพ: 3 ใบ (สกิลใหม่/อัพ/ตรง synergy tag การันตี 1 ใบ) + reroll ด้วย Fate Shard (มี pity)
- ความหายาก Common 55 / Rare 28 / Epic 12 / Legendary 4.5 / Mythic 0.5 (%); Mythic จากการสุ่มหรือสูตรเฉพาะเท่านั้น

## 7. Fusion (กติกาฉบับเดียว)
1. เมื่อมีสกิล 2 ตัวที่ตรงสูตรและทั้งคู่ Lv3+ → การ์ดผสมโผล่เป็น **ใบที่ 4** ใน Draft (ไม่แย่ง 3 ใบ) ไม่ต้องใช้ Fusion Core
2. ผสมแล้ว 2 สกิลเดิมหายไป ได้สกิลใหม่ 1 ตัว คืนช่องว่าง 1 ช่อง; สกิลใหม่เป็น Active/Passive ตามสกิลต้นทางที่เลเวลสูงกว่า (เท่ากัน = ที่ได้มาก่อน) จึงมีช่องประเภทนั้นว่างเสมอ; เริ่มที่เลเวลของสกิลต้นทางที่สูงกว่า และยก Skill XP ของสกิลนั้นมาด้วย
3. 1 สูตร 2 ผลลัพธ์ ขึ้นกับสกิลที่เลเวลสูงกว่า; เลเวลเท่ากัน = ใช้ผลของสกิลที่ได้มาก่อน (เช่น เตะฝุ่นสูงกว่า → ทอร์นาโดเพลิง; จุดไฟติดยากสูงกว่า → กองไฟเดินได้)
4. Fusion Core ใช้เฉพาะสูตร Mythic หรือดันความหายาก +1
5. MVP 10 สูตร = 20 ผลลัพธ์, สารานุกรม ??? 2 ช่อง/สูตร. ตัวอย่างฮา: ขว้างหิน + สะดุดล้ม = อุกกาบาตตกใส่ตัวเอง (เสีย 10% Max HP เหลือขั้นต่ำ 1 HP, ดาเมจ ×5, CD 8 วิ)
6. เป้า: ผสมเองครั้งแรกภายในคืนที่ 3 (sim ต้องยืนยันว่า 2 สกิลถึง Lv3 ใน ~5 นาที)

## 8. "ระบบ" (บุคลิก)
- พูดกวนหน้าตาย, ภารกิจรายวันสั้นๆ, อีเวนต์ระบบ 1–2 ครั้ง/รอบ (เช่น ขอแลกสกิลห่วยกับกล่องสุ่ม), คำพูดบนหน้าตาย, ตั้งชื่อ build แบบนิยาย isekai บนการ์ดแชร์
- ไฟล์ข้อความ TH/EN เขียนมุกแยกให้ตลกในแต่ละภาษา

## 9. Meta progression
- Soul Shard ต่อคืนที่รอด 1–7 = 5/7/9/11/13/15/20 (รวม 80) + ภารกิจ/บอส; ชนะ +30%; ยอมแพ้ (กลางวันเท่านั้น) ×0.6; แพ้ ×0.5
- ปลดล็อก: ชาติก่อน (หมอ/เชฟ/ทหาร/วิศวกร ให้ passive), คลังสกิลใน pool, reroll, เสบียงติดตัว, สมุดสูตรถาวร

## 10. Save
- บันทึก snapshot (มี version) เมื่อปิดแอป/สลับแท็บ เปิดกลับมาเล่นต่อ; เก็บสถานะ RNG ทุกสาย (map/loot/draft/combat/event) และตัวเลือกที่ค้าง (Draft, อีเวนต์, ทางเลือกเย็นนี้) → เปิดกลับมาเห็นชุดเดิม
- Daily Seed ไม่มี checkpoint; resume ได้ภายใน 60 วิ เกินแล้วนับเป็นตาย. เกม pause เมื่อสลับแท็บ. ใช้ navigator.storage.persist() + export save

## 11. UI/แชร์
- Mobile-first joystick + auto-aim; หน้าสรุปรอบแสดงดาเมจต่อสกิล + เวลาที่ผสมสำเร็จ; การ์ดแชร์ (ชื่อ build, วันที่รอด, สกิล, ลิงก์ ?seed=)
- Art: พาเลตจำกัด สีประจำ แดงจันทร์เลือด + ม่วงรอยแยก; thumbnail อ่านออกที่ 512px

## 12. Tech
Phaser 3 + TS + Vite, Cloudflare Pages; สกิลประกอบจากชิ้นส่วน JSON (projectile/aoe/aura/dot/buff/summon + modifier + tags); stat pipeline เดียว; event bus; object pool + spatial hash; มอน steering ตรงเข้าหา (flow field ทีหลังเมื่อมีกำแพง); seeded RNG แตกสาย; state แยกจาก render; headless sim

- ไม่ขาย Shard/Fate Shard, ไม่ pay-to-win. เว็บ: rewarded ads เลือกดูเอง; ปิด ads ในโหมด Daily; การ์ดแชร์ของรอบที่ใช้ ads มีเครื่องหมายกำกับ. ระยะยาว: เวอร์ชันเต็มขายขาด (Steam) + cosmetic
